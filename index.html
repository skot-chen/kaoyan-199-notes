3 小时怎么分

  1. 逻辑 55 分钟（第26–55题）：单题先做，大题组（1拖2）放最后。1 题超过 2.5 分钟就猜。
  2. 写作 60 分钟：论证有效性分析 25 分钟，论说文 35 分钟。
  3. 数学 60 分钟（第1–25题）：只做“必做”题型，每题最多 2.5 分钟。
  4. 最后 5 分钟：所有空着的题按下面的统计涂满。不倒扣分，一个都不能空。

数学放最后的原因：数学是你最弱的，就算时间不够也可以靠猜拿一部分分；作文没写完是 0 分，逻辑没做是白丢。

第一步：条件充分性判断（10题30分，最值钱）

5 个选项的意思 必会

题目问的是：条件能不能推出结论（不是让你算结论对不对）。

选条件(1)条件(2)口诀
A✔ 行✘只有一行
B✘✔ 行只有二行
C✘✘两个合起来才行
D✔✔各自都行
E✘✘合起来也不行

口诀：A 一、B 二、C 联合、D 都行、E 都不行。

6 个秒判技巧 必会

  1. 小推大 = 充分：条件的范围在结论范围里面 → 充分。例：条件 x=2，结论 x>1 → 充分。反过来 x>1 推不出 x=2。
  2. 找反例：从条件里挑最“怪”的数代进结论：0、负数、1、两个数相等、数列取常数列。一个反例 = 不充分。
  3. 两个未知数，单个条件只给一个式子 → 单独都不够，多半是 C。
  4. 两个条件长得一样只是数字不同（比如(1) a=2、(2) a=3）→ 不可能是 C，多半是 A / B / D / E 中一个。
  5. 两个条件互相矛盾（不可能同时成立）→ 不选 C。
  6. 不会就选 C（18年统计最多）。

顺序：先把结论化简（算出它要的范围），再分别代条件(1)、(2)。单独都不行才考虑联合。

第二步：问题求解的 6 个邪修

不会算也能选 必会

  1. 代入选项：应用题（求人数、天数、价格）直接把选项代回题目。从中间的 C 开始代，大了往小代、小了往大代。
  2. 特值法：题目说“任意”“恒成立”或选项是式子 → 令 x=0、x=1；数列令所有项相等；三角形取等边或直角三角形。
  3. 倍数排除：比例题答案一定是“份数”的倍数。例（2009第2题）：最后男:女 = 30:19 → 总人数是 49 的倍数 → 选项里只有 686、637 是 49 的倍数，二选一（答案 637）。
  4. 画图目测：几何题图一般按比例画，算不出就比一比长度/面积，选最接近的。
  5. 范围排除：概率一定在 0 到 1 之间；面积、长度不能是负数；估算一下，把离谱的选项划掉。
  6. “至少”用反面：P(至少一个) = 1 − P(一个都没有)。

第三步：公式卡（按考频排序）

应用题（每年约 6 题）★★★★★必会

  • 利润：利润 = 售价 − 成本，利润率 = 利润 ÷ 成本（除的是成本）
  • 先涨 x% 再降 x%：比原来少 x²%。同价卖出一个赚 20% 一个亏 20% → 一定亏。
  • 连续增长：现值 = 原值 × (1+p)ⁿ
  • 浓度：浓度 = 溶质 ÷ 溶液；加水时溶质不变，蒸发时溶质也不变。
  • 相遇：路程 = (v₁+v₂)·t　追及：路程差 = (v₁−v₂)·t
  • 流水：顺水 = 船速+水速，逆水 = 船速−水速
  • 工程：总工作量设成 1（或设成几个天数的最小公倍数），效率 = 1 ÷ 天数，合作效率相加。
  • 两集合容斥：A∪B = A + B − A∩B；都不 = 总数 − A∪B
  • 三集合：A∪B∪C = A+B+C − (两两交) + 三交
  • 平均数混合（十字交叉）：两组平均分 a、b，混合后 c → 人数比 = (c−b) : (a−c)
  • 阶梯收费/分段：先算“刚好到分界点”是多少钱，再看超出部分。

代数：方程、绝对值、不等式（每年约 5 题）★★★★★必会

  • 一元二次 ax²+bx+c=0：Δ = b²−4ac，Δ>0 两根，Δ=0 一根，Δ<0 无实根
  • 韦达：x₁+x₂ = −b/a，x₁x₂ = c/a
  • 常用变形：x₁²+x₂² = (x₁+x₂)² − 2x₁x₂，1/x₁+1/x₂ = (x₁+x₂)/(x₁x₂)，|x₁−x₂| = √Δ / |a|
  • 一正一负两根 ⇔ c/a < 0
  • 二次函数对称轴/顶点：x = −b/(2a)；a>0 开口向上有最小值
  • 绝对值的意思 = 距离：|x−a| 是 x 到 a 的距离
  • |x−a| + |x−b| 的最小值 = |a−b|（x 在 a、b 中间时取到）
  • |x−a| − |x−b| 的范围 [−|a−b|, |a−b|]
  • 均值不等式：a+b ≥ 2√(ab)（a、b 正数，a=b 时取等号）。积一定 → 和最小；和一定 → 积最大。例（2024第4题）：x² + 16/x² ≥ 2×4 = 8
  • 余数定理：f(x) 除以 (x−a) 的余数 = f(a)
  • 乘法公式：(a±b)² = a² ± 2ab + b²，a²−b² = (a+b)(a−b)，a³±b³ = (a±b)(a² ∓ ab + b²)

平面几何（每年约 3 题）★★★★必会

  • 三角形面积 = ½ × 底 × 高；高相同 → 面积比 = 底的比
  • 相似三角形：面积比 = 边长比的平方
  • 勾股数：3-4-5、5-12-13、6-8-10、8-15-17
  • 特殊直角三角形：30°-60°-90° 三边 1 : √3 : 2；45°-45°-90° 三边 1 : 1 : √2
  • 等边三角形面积 = (√3/4)·a²
  • 圆：面积 = πr²，周长 = 2πr；扇形 面积 = (圆心角/360°)·πr²
  • 梯形面积 = (上底+下底) × 高 ÷ 2
  • 阴影面积：整体 − 空白，或者把阴影块“割下来补到别处”拼成规则图形。
  • 直径所对的圆周角 = 90°

概率 + 排列组合（每年约 3 题）★★★★必会

  • 组合（不管顺序）：C(n,m) = n! / (m!(n−m)!)；例 C(5,2) = 10，C(n,m) = C(n, n−m)
  • 排列（管顺序）：A(n,m) = n! / (n−m)!；例 A(5,2) = 20
  • 必须相邻 → 捆绑：捆成 1 个一起排，内部再排
  • 不能相邻 → 插空：先排其他人，再把这些人插进空位
  • 相同的东西分给人，每人至少 1 个 → 隔板：n 个分给 m 人 = C(n−1, m−1)
  • 平均分组（几组人数一样）要再除以 组数!
  • 错排（都不在自己的位置上）：2 个→1 种，3 个→2 种，4 个→9 种，5 个→44 种
  • 古典概率 = 符合的种数 ÷ 总种数
  • 独立事件同时发生：P(A且B) = P(A)·P(B)
  • n 次里恰好 k 次成功：C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
  • 至少一次 = 1 − 一次都没有

数列（每年约 2 题）★★★★必会

  • 等差：aₙ = a₁ + (n−1)d，Sₙ = n(a₁+aₙ)/2
  • 等差下标性质：m+n = p+q → aₘ+aₙ = aₚ+a_q；n 是奇数时 Sₙ = n × 中间那一项
  • 等差的 Sₙ, S₂ₙ−Sₙ, S₃ₙ−S₂ₙ 也成等差
  • 等比：aₙ = a₁·qⁿ⁻¹，Sₙ = a₁(1−qⁿ)/(1−q)（q≠1）
  • 等比下标性质：m+n = p+q → aₘ·aₙ = aₚ·a_q
  • 三个数成等差 2b = a+c；成等比 b² = ac
  • 邪修：只给“等差/等比”没给具体数 → 设成常数列（d=0 或 q=1）代进去试。条件充分题里常数列常常就是反例。

解析几何（每年约 2 题）★★★能做就做

  • 斜率 k = (y₂−y₁)/(x₂−x₁)；平行 k 相等；垂直 k₁·k₂ = −1
  • 两点距离 √((x₂−x₁)² + (y₂−y₁)²)；中点 ((x₁+x₂)/2, (y₁+y₂)/2)
  • 点到直线 Ax+By+C=0 的距离 = |Ax₀+By₀+C| / √(A²+B²)
  • 圆：(x−a)² + (y−b)² = r²，圆心 (a,b)
  • 圆的一般式 x²+y²+Dx+Ey+F=0：圆心 (−D/2, −E/2)
  • 直线和圆：圆心到直线距离 d，d<r 相交，d=r 相切，d>r 相离；弦长 = 2√(r²−d²)
  • 两圆：圆心距 d 和 r₁+r₂、|r₁−r₂| 比大小
  • 关于 y=x 对称：(x,y) → (y,x)；关于 y=−x：(x,y) → (−y,−x)
  • 邪修：在草稿纸上画坐标，点和圆都画出来，很多题可以直接看出来。

整数、实数、平均数方差（每年约 2 题）★★★能做就做

  • 20 以内质数：2, 3, 5, 7, 11, 13, 17, 19；2 是唯一的偶质数（几个质数加起来是奇数/偶数 → 想想有没有 2）
  • 整除：被 3（9）整除 ⇔ 各位数字之和被 3（9）整除；被 4 整除看最后两位；被 5 看个位
  • 奇偶：奇+奇=偶，奇+偶=奇，奇×任何偶=偶
  • 平均数 = 总和 ÷ 个数
  • 方差 = 平方的平均数 − 平均数的平方；所有数都加 c，方差不变；都乘 k，方差变 k² 倍
  • 数据越分散，方差越大（看图/看数字直接比）

立体几何（每年约 1 题）★★只背这几个

  • 长方体：体对角线 √(a²+b²+c²)，表面积 2(ab+bc+ca)
  • 正方体（边长 a）：外接球半径 √3·a/2，内切球半径 a/2
  • 圆柱：V = πr²h，侧面积 2πrh
  • 圆锥：V = ⅓πr²h
  • 球：V = (4/3)πR³，表面积 4πR²

你的笔记里有 1 个公式写反了，先改：
“只有 B 才 A” = A → B，它的逆否是 ¬B → ¬A（没 B 就没 A），不是 ¬A → ¬B。
例：只有努力才能考上 = 考上→努力；逆否：不努力→考不上。“没考上→不努力”推不出。

形式逻辑（你已经练的，压缩版）

翻译成箭头 必会

中文箭头
如果A就B / 只要A就B / A则BA → B
只有B才A / A离不开B / A必须B / A需要BA → B（“只有、必须”后面的放箭头后）
除非A否则B / 除非A才不B¬A → B（除非 = 如果不）
A除非B（= 除非B否则不A）¬B → ¬A = A → B

只能用两条：肯前推肯后、否后推否前。否前、肯后都推不出。

3 个变形公式 必会

  • 箭头变“或”：A → B = ¬A ∨ B（前面加非，后面不变）
  • 否定箭头：¬(A → B) = A ∧ ¬B（前照抄，后加非，用“且”连）
  • 德摩根：¬(A∧B) = ¬A ∨ ¬B，¬(A∨B) = ¬A ∧ ¬B（且、或对调）
  • 或的推理：A或B + 非A → B 有效；A或B + A → 非B 无效
  • 要么A要么B：一个真另一个一定假

直言命题和“矛盾” 必会

原句矛盾（一真一假）
所有S是P有的S不是P
所有S不是P有的S是P
必然P可能不P
至少5个至多4个
A且B非A或非B
A→BA且非B

“有的”= 至少一个，不排除所有。“有的是”和“有的不是”可以同时真，不能同时假。

真假话题：先找矛盾的两句，它们必有一真一假，再推剩下的。

论证逻辑（每年约 12–15 题，最稳的分）

3 步走 必会

  1. 看问题：削弱 / 加强 / 假设 / 解释 / 结构相似。
  2. 找论据和结论，看两者是不是说的同一件事。不一样 → 答案就是“搭桥”（加强）或“拆桥”（削弱）。
  3. 看到因果词（导致、因为、所以、是……的原因）→ 削弱首选：另有他因、因果倒置；加强首选：排除他因、说明机制。
  • 假设题：把选项变成否定，题干马上不成立 → 就是答案。
  • 解释题：答案要能让“表面矛盾的两件事”都成立，找第三个因素。
  • 结构相似：只看骨架，翻成字母 A→B，非B，所以非A，找一模一样的。
  • 不选的：诉诸无知（“尚无证据证明……”）、和题干无关的、只说“有人认为”的。

综合推理 / 大题组（近年每年 3–5 组，最费时）

邪修做法 放最后做

  • 放到逻辑最后做：一组 2 题要 5 分钟，单题 1.5 分钟一道，先拿单题的分。
  • 选项代入排除：题目问“可能为真/一定为真”时，不要从头推，直接把选项一个个代进条件，矛盾的划掉。
  • 先用“确定的信息”：题干里直接说死的（如“甲在第3位”）先填进表格，再用箭头条件。
  • 画表格：人 × 位置/科目，打 ✔ ✘。
  • “至少/至多/恰好”数量题：先找数量最紧的那条（例如 5 人选 4 个），往往一下推出很多。

你最常踩的 3 个坑 必会

  1. 箭头变“或”时，多否了后件（应该是 ¬A ∨ B，后面不变）。
  2. 求矛盾时把“或”写成“且”（¬(A∧B) = ¬A ∨ ¬B，要对调）。
  3. 把“有的”当成“只有一些”（“有的”可以是全部）。

论证有效性分析（30分，600字，25分钟）

9 个缺陷 + 怎么一眼认出来 必会

缺陷名看到什么就想到它
偷换概念前后两个词很像但意思不同（“使用”→“拥有”，“年轻人”→“所有人”）
以偏概全 / 样本不足几个人、一次调查、某个城市 → 推出“全体”“普遍”
强加因果“因为……所以……”“导致”，两件事只是同时出现或先后出现
混淆充分必要（假言不当）“只要……就……”“只有……才……”“不……就不能……”
不当类比“就像……一样”，拿 A 的经验套到 B（猴群→明星）
非此即彼（假两难）只给两个选择，忽略了中间情况
自相矛盾前面说 X，后面又说和 X 相反的话
数据误用只看百分比不看总数、只看平均数、比较的基数不一样
推断绝对化 / 论据不足“必然”“一定”“势必”“完全”——结论说得太满

考试时：读材料，每句话旁边标一下，找出最明显的 4 个就够了，不用找全。

万能结构（直接背） 必会

标题：XX 真的能 XX 吗？ 或 XX 未必 XX（不加书名号）

开头（约 60 字）：上述材料通过……，得出了“……”的结论。然而，其论证过程存在多处逻辑漏洞，现分析如下。

中间 4 段（每段约 120 字），每段 3 句：

  1. 【指出】首先，材料由“A”推出“B”，存在XX（缺陷名）之嫌。
  2. 【反驳】即使 A 属实，也未必能得出 B。因为……（举一个另外的可能/反例）。
  3. 【收尾】因此，该推理难以成立。

四段开头用：首先 / 其次 / 再次 / 最后。

结尾（约 40 字）：综上所述，由于上述论证存在诸多漏洞，“……”的结论难以必然成立。

论说文（35分，700字，35分钟）

近 4 年题目都是“两个东西的关系” 必会

  • 2023：领导艺术，像指挥乐队演奏
  • 2024：发散性思维（与众不同）
  • 2025：想被认可 → 接受别人的评价标准
  • 2026：观众有全景视角，球员在场上看不到全局

审题公式：找出材料里的两个东西（全局↔一线、个性↔标准），观点写成：“二者都重要，关键在于结合 / 换位 / 找到平衡”，再落到企业管理上。不要写成只夸一边的口号文。

五段式结构（直接背） 必会

  1. 标题：直接写观点，4–10 个字。例：《既要全景之眼，也要临场之功》
  2. 第 1 段（约 100 字）：一两句概括材料 → 亮出中心观点（这一句一定要有）。
  3. 第 2 段 是什么/为什么（约 150 字）：分论点句 + 道理 + 一个例子。
  4. 第 3 段 为什么/反面（约 150 字）：如果不这样会怎样 + 一个例子。
  5. 第 4 段 怎么做（约 150 字）：对企业/管理者提 2–3 条做法。
  6. 第 5 段 结尾（约 80 字）：重复中心观点，升华一句。

万能企业例子（方向通用，提前想好怎么用）：华为长期投入研发、海尔砸冰箱抓质量、柯达不转型被数码相机淘汰、诺基亚错过智能手机。
